# Cynbit Technologies – Website QA Testing Assessment

## About the Project

This repository contains the manual website testing work completed as part of the Cynbit Technologies QA Testing Intern assessment.

The main aim was to check whether the important website features were working properly from a user's point of view.

## Testing Details

**Testing Type:** Manual Testing  
**Testing Date:** 26 November 2026  
**Role:** QA Testing Intern Candidate

## Testing Scope

The following areas were covered during testing:

- Homepage navigation
- Careers page functionality
- Contact form email validation
- Mobile responsiveness
- Contact form behaviour after page refresh
- Footer email link

## Testing Results

The tested features worked as expected in the scenarios covered.

- Homepage navigation was working.
- Careers page was accessible.
- Invalid email formats were handled with a validation message.
- The website worked properly on my mobile phone in the areas checked.
- Unsubmitted form details disappeared after refreshing the page, which was expected behaviour.
- The footer email link did not open the mail application on my laptop and requires further verification.

**Confirmed Bugs:** No confirmed bugs found in the tested scenarios.

## Documents Included

1. **QA Audit Report** – Contains the testing summary, observations and improvement recommendations.
2. **Test Cases and Bug Report** – Contains the test scenarios, expected results, actual results and their status.
3. **Recommendations** – Suggestions that may help improve the website's user experience.
